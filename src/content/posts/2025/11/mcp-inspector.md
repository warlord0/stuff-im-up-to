Following on from [Building My Own Novel-Writing Assistant](/posts/building-my-own-novel-writing-assistant/) I discovered the [MCP Inspector](https://modelcontextprotocol.io/docs/tools/inspector#installation-and-basic-usage).

This is a great tool for testing my MCP server without using an AI. I can list what tools I have in the MCP and run them with parameters. It’s like a “postman” for MCP Servers. The nice thing about it is that it does not need to be installed, just run it with `npx`.
