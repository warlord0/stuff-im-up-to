The [curated palettes post](/posts/colour-palettes/) is a list: nine named palettes, pick the one that fits. This is the other way round - pick one colour, and get a palette built from it.

Give it a base colour and a mood (Calm, Bold, Dark, Neon, and so on) and it derives a primary, an accent, a background, a surface and a text colour from it, all in OKLCH so the lightness and chroma stay predictable across hues. The preview updates live, each swatch shows its contrast ratio against the ones it'll actually sit next to, and clicking a swatch sets it as the new base colour to riff from. Copy the result as CSS variables, or save it to come back to later. Saved palettes are stored in your browser's local storage - nothing is sent anywhere, and this site doesn't keep a copy of anything you make.

Click through the modes to see how differently the same base colour reads as Pastel versus Bold versus Dark. The maths is Björn Ottosson's OKLab/OKLCH, chosen because moving lightness or chroma doesn't drag hue along with it the way HSL does, so the recipes can say "the same hue, but darker" and mean it.
